# Hilsham & Associates — marketing site

Vite + React marketing site for Hilsham & Associates (Kenya).

## Run locally

```bash
npm install
npm run dev
```

Preview production build:

```bash
npm run build
npm run preview
```

Optional contact email: copy `.env.example` to `.env` and set `VITE_CONTACT_EMAIL`.
